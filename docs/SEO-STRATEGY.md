# SEO strategy — Aravind Invisible Grills

Primary market: **Hyderabad, Telangana**. The site represents the complete safety and installation business, not only invisible grills. All copy is original; competitor names are not used as site keywords or branding.

## 1. Architecture

| Layer | Implementation |
| --- | --- |
| **Service granularity** | 33 dedicated root-level service pages: 14 featured services plus 19 specialised applications. Each has unique metadata, intro, benefits, applications, materials, installation steps, FAQs and related links. |
| **Location targeting** | 18 location pages: Hyderabad hub, 14 dedicated area pages, and 3 service × location guides. Areas are service locations only; no branch addresses are invented. |
| **Internal linking** | Home → all featured services + expandable additional services; service pages → related services + area guides; location pages → relevant services + nearby areas; footer → hubs and key areas; visible breadcrumbs + BreadcrumbList schema. |
| **Content quality** | One H1 per page; unique titles/descriptions/H1s enforced by the build. Location copy discusses property type, access, approvals and preparation rather than spinning keywords. |
| **Structured data** | Organization + LocalBusiness, WebSite, WebPage/CollectionPage/AboutPage/ContactPage, Service, BreadcrumbList and FAQPage where FAQs are rendered. |
| **Technical SEO** | Pre-rendered HTML, canonicals, sitemap, robots.txt, OG/Twitter metadata, responsive AVIF/WebP images, lazy loading, self-hosted fonts, 301 legacy redirects and a noindex 404. |

## 3. Content quality rules

- No duplicate or thin location pages: each area has unique local paragraphs, a checklist, FAQs and relevant service links.
- No guaranteed rankings, rust-proof promises or universal safety claims. Grills/nets are additional protective measures; supervision and suitable railings remain necessary.
- Nallagandla is explicitly the Hyderabad suburb, not Nalgonda town/district.
- Gallery images are labelled as references, not verified customer projects. Existing testimonials are displayed with an authenticity note and no aggregate rating schema.

## 4. Off-page next steps (outside this codebase)

1. Create/verify a Google Business Profile for the service area; keep name, phone and hours consistent.
2. Request genuine reviews and replace reference imagery with real project photos over time.
3. Confirm warranty, installation-count and testimonial claims with the business.
4. Build consistent local citations and genuine community/supplier links.
5. Monitor Search Console queries, indexed pages, Core Web Vitals and mobile usability; expand content only where demand and unique value justify it.
